# MANUFACTURING ATLAS — technological continuity

A **new node inside the original ATLAS FORGE federation**, original domain slot #10, not a new top-level Atlas. The scientific purpose is to reconstruct manufacturing mathematics, metrology, tolerances, machine kinematics, materials processing, quality evidence, and process dependencies needed to make parts and eventually computers.

- 18 original human-readable chapters with derivations, worked investigations, assumptions, invalid cases and authoritative bibliographic pointers.
- Standard-library reference kernels, deterministic constructed casebook and independent numerical oracle (NumPy optional).
- 8 immutable revision JSONL collections, source-linked exact-revision records and cross-domain navigation.
- Full-federation tests, protected historical files and SHA-256 verified incremental recovery.

Read `docs/REFERENCE_GUIDE.md`, `docs/DEPTH_MANUAL_v0.1.0.md`, and `docs/SCOPED_V1_GATES.md`. Run `python -m manufacturing_atlas`; `python -m unittest discover -s tests -q`.

**Boundaries:** Does not claim actual machine calibration, safe machining parameters, verified semiconductor fabrication, functioning CPU, independent scientific peer review, or authenticated original publisher file bytes. Original 30-domain roadmap and deferred Bitwork router remain unchanged.
