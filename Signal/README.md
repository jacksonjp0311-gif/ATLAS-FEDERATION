# Signal — preserved federation reference

> Supplementary publication guide for this public mirror. This guide is new; the reference files below retain their original bytes.

This directory preserves the **Signal reference subset inside the original federation**. It contains scientific records, a frozen reference snapshot, and historical context receipts. It is not a complete standalone Signal Atlas application.

The [publication manifest](../evidence/publication/four-domains-2026-11-20-manifest.json) identifies original archive locations, hashes, and any holds. Historical receipts describe their own full-federation context; they are not fresh checks of this subset. Source-specific rights and evidence limits remain attached to the records.

The separate [Signal Atlas research project](https://github.com/jacksonjp0311-gif/SIGNAL-ATLAS) develops research amortization. It has its own versions and provenance; it does not replace this exact historical subset.
