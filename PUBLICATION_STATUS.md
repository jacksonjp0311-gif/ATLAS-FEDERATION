# Atlas Federation — public publication status

This repository is the public source mirror of the original **ATLAS FORGE** federation. The canonical Library source remains unchanged. The preserved checkpoint is **Compiler Design v0.2.0**.

## What can be browsed

The [domain directory](README.md#domain-directory) provides entry points for all 24 checkpoint nodes. The [canonical source directory](PUBLIC_SOURCE_DIRECTORY.md) maps the cleared source layout under [`canonical/`](canonical/), including preserved scientific records, documentation, models, and eligible history. The [browsable notice](canonical/PUBLIC_BROWSABLE_NOTICE.md) and [browsable file manifest](canonical/BROWSABLE_FILE_MANIFEST.json) describe the repository export; [nested-source provenance](canonical/_nested/PROVENANCE.json) identifies expanded archive members. The [four-domain export manifest](evidence/publication/four-domains-2026-11-20-manifest.json) retains exact provenance for the earlier Computer Architecture, Mathematics / Physics, Signal, and Cymatics exports. The [earlier cleared-source batch receipt](evidence/publication/cleared-domain-source-batch-2026-11-20.json) records the subsequent 1,948-file export from 19 domain roots. These historical publication scopes remain distinct from the current derivative.

Public material is a **derivative with explicit omissions and documented redactions**. Read the [derivative notice](canonical/PUBLIC_DERIVATIVE_NOTICE.md), [omission inventory](canonical/PUBLIC_OMISSION_MANIFEST.json), and [public file manifest](canonical/FILE_MANIFEST.json). The inventory identifies excluded content, affected files, and the review basis. Unmodified original files retain their byte identity; redacted files and rebuilt metadata have new hashes. General methods and bibliography are preserved where permitted, while examples dependent on removed data remain unavailable. These transformations are not scientific corrections or new successful experiments.

## Evidence and rights

Historical test and restoration receipts retain their original edition and scope. They are not fresh checks of the public derivative. The archive `FILE_MANIFEST.json` covers the release package, including eligible nested archive containers. The repository `BROWSABLE_FILE_MANIFEST.json` covers the browsable export, which excludes ZIP/WHL containers and exposes nested source separately. Per-source permissions and notices remain applicable. Public access does not create a blanket license. Follow [restoration instructions](RESTORATION.md), [rights and reuse](README.md#rights-and-reuse), and the public review receipts before relying on or redistributing this material.
