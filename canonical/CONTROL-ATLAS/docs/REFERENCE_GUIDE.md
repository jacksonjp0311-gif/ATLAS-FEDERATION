## Executable methods
`python -m control_atlas v1-casebook` for authored casebook; `python -m control_atlas openmct-review /path/to/raw_data.txt` for an **operator-supplied** authenticated file; `python -m control_atlas openmct-fit /path/to/raw_data.txt` attempts a chronological ARX holdout or explicitly refuses it.
No source files are fetched by the CLI; it does not touch hardware. The OpenMCT publisher raw dataset has not been analyzed in this release.
