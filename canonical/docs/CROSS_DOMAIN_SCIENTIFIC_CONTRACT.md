# A contract for connecting humanity's knowledge without flattening it

The common schema already stores record revision, source IDs, assumptions, limits and typed relations. The future Bitwork router must preserve these existing fields; it must not depend on private source text that was never acquired. Every future cross-domain edge needs the **type** (prerequisite, compatible transformation, empirical support, contradiction, application, incompatible assumptions), the **source/derivation**, the **model and unit basis**, and a **reversibility or transfer caveat**.

Examples of defensible conceptual cross-links:

- Measurement uncertainty and sensor calibration **qualify** Control's state-estimation bounds; passing a numerical controller test cannot substitute for calibration evidence.
- Causal confounding and target-trial design **qualify** claims that an agent memory update or manufacturing process change produced better outcomes; paired observational gains do not automatically identify causality.
- Materials temperature-dependent properties **support conditionally** Control heat-flow/actuator models, but the material and temperature domains must match.
- Agent trace lineage and mutation effects **depend on** reliable distributed-system idempotency and durable execution, future topics in the separate domain queue.
- Scientific derivations in Computation **supply algorithms** that can be used by all nodes, but algorithm correctness does not establish that a physical model or data source is valid.

A future AI answer must distinguish these relations. Do not treat high semantic similarity as evidence that a concept has the same units, assumptions or intervention scope. An absent contradiction edge is not evidence that no contradiction exists.

**Status:** a design contract and worked conceptual examples only, not a live cross-domain router or verified links created for future unbuilt domains. The thirty-domain content program must finish before new routing implementation.
