# ATLAS FORGE — Human Knowledge Survival Program

Eight nodes, 1,475 versioned records, 707 relationships and 396 source cards. Computation Atlas has reached **scoped content v1.0.0** with original mathematical explanations, tests and reproducible cases, but the collection is **not yet a comprehensive offline copy of humanity's knowledge**.

Read the [Human Knowledge Survival Charter](docs/HUMAN_KNOWLEDGE_SURVIVAL_CHARTER_v1.md) and the [offline reconstruction guide](docs/OFFLINE_RECONSTRUCTION_RUNBOOK.md). These are release acceptance standards, not a claim the archive has passed all their requirements.

## Eight domain nodes

Signal, Cymatics, Measurement, Causal, Materials, Control, Agent and **Computation**. Earlier seven node data and code remain byte-for-byte identical. Full Computation reference: [50 chapters](COMPUTATION-ATLAS/docs/REFERENCE_GUIDE.md), [manual](COMPUTATION-ATLAS/docs/DEPTH_MANUAL_v1.0.0.md), [source register](COMPUTATION-ATLAS/docs/SOURCE_REGISTER.md), [validation](COMPUTATION-ATLAS/docs/VALIDATION_v1.0.0.md).

The 396 bibliographic cards include **zero original publisher documents with authenticated local raw bytes** under the strict source-acquisition audit. Linked citations and original instructional prose are useful but not equivalent to recoverable primary sources. Publisher material remains linked and paraphrased; rights remain with owners.

**Program order:** all thirty knowledge domains first; Bitwork routing last; then integrated evaluation and desktop transfer. The shared Forge router has not changed. **Language Atlas is queued, not yet built.**
