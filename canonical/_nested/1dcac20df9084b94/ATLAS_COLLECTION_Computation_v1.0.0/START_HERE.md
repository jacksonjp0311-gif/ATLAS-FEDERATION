# ATLAS FORGE — Computation scoped content v1

The complete collection is readable offline. Start with `docs/HUMAN_KNOWLEDGE_SURVIVAL_CHARTER_v1.md`, then `COMPUTATION-ATLAS/docs/DEPTH_MANUAL_v1.0.0.md`. The original chapters include assumptions, equations, reconstruction exercises, source URLs, limitations and counterexamples.

With Python 3.10+, run `python tools/survival_audit.py --root . --check-files` after sealing the archive, `python tools/check_manifest.py verify .`, and `python tools/check_collection.py --out /a/new/output/folder`. These checks verify bytes and structure, not the underlying scientific truth of every statement.

Computation Atlas includes exact-revision JSONL source cards and source-closed context. The standalone package drops five cross-node links whose targets live only in the complete collection. Earlier nodes, their tests and the shared routing kernel remain unchanged. All 30 domains must be built before implementing Bitwork routing or transferring to desktop.
