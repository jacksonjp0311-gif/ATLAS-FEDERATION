**James Paul Jackson research program · 14 November 2026 · Common Atlas Contract 1.0**

## Reproduce offline

```sh
python -m language_atlas
python -m language_atlas advanced
python -m unittest discover -s tests -q
python tools/numerical_oracle_v0.2.0.py  # optional NumPy
```

New methods provide token alignment, corpus BLEU without smoothing, small CNF probabilistic grammar parsing, genealogically conditioned descriptive fractions, historical segment-pair counts, community-rights metadata gates, and simultaneous speech/sign annotation tiers.

**Every new example is constructed.** No authentic audio, sign-language video, language treebank, WALS/CLDF corpus, community consent record or real translation benchmark has been imported. A bibliographic source card does not contain the primary publisher's bytes. Unicode 18 UAX 29 normative grapheme segmentation is not implemented and should never be inferred from simple Python code-point counts.
