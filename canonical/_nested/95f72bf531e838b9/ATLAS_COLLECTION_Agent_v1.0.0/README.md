# ATLAS FORGE — Human Knowledge Preservation Program

**Thirty scientific content domains first. Bitwork routing last. Integrated evaluation and desktop transfer afterward.**

ATLAS FORGE is a source-linked research knowledge library meant to preserve *usable reasoning*: original explanations, mathematics, conditions, evidence, contradictions, reproducible methods, versioned records and scientific omissions. It is **not yet a complete offline archive of humanity's scientific publications**, and does not claim independent scientific certification.

## The preservation commitment

Read the [Human Knowledge Survival Charter](docs/HUMAN_KNOWLEDGE_SURVIVAL_CHARTER_v1.md), the [offline reconstruction runbook](docs/OFFLINE_RECONSTRUCTION_RUNBOOK.md) and [cross-domain scientific contract](docs/CROSS_DOMAIN_SCIENTIFIC_CONTRACT.md). An offline [survival audit](tools/survival_audit.py) distinguishes hash/reference integrity from the missing original source documents.

## Current scientific collection

Agent Atlas v1.0.0 is a *scoped content edition* with [50 chapters and 32 investigations](AGENT-ATLAS/docs/REFERENCE_GUIDE.md). The previous 158 Agent records and 101 relationships are immutable.
