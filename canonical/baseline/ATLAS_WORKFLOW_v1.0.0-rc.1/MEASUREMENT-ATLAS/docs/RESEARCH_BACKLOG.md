# Measurement v1 remaining work

Measurement is the active Atlas until all eight shared gates pass. An intermediate release does not authorize opening Causal Atlas.

1. Scope: complete units/dimensions, richer calibration examples and explicit conformity-decision boundaries; review and freeze the question families.
2. Evidence: independently review release-critical primary locators and derivations. The current twenty new records are bounded assistant checks, not scientific certification.
3. Tools: expand unit-aware cases and nonlinear limits without pretending a declared first-order model covers every measurement.
4. Integration: connect a pinned actual Bitwork prototype/encoder map to exact Atlas IDs and then to an actual consuming AI. The current receipt bridge is not that execution.
5. Evaluation: independently authored frozen queries, semantic and Bitwork baselines, same-corpus/same-budget comparison, actual answer quality and abstention.
6. Release: verify Windows and Linux, direct browser integration and clean deployments; keep the criterion freeze and all evidence receipts explicit.

The candidate acceptance standard lives in the companion Forge `workflow/acceptance.json`. Do not turn green arithmetic tests into a passed scientific or integration gate.

## 0.6.0 progress

One NIST published calibration dataset has been numerically reanalyzed from checked decimal tokens. Certified numeric targets match; handbook-display discrepancies remain visible. This advances real-data content but does not supply original source bytes, a traceable certificate, independent laboratory repetition or independent review. Measurement v1 is still blocked. Next content priorities are certificate interpretation, complete uncertainty budgets and additional independently documented cases.
