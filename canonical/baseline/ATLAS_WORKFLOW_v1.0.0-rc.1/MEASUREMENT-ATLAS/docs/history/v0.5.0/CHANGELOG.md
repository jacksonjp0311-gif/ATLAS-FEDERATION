## 0.5.0 — 2026-11-12

Content-first Measurement expansion: 30 new bounded reference records, 17 additional primary source pages, eight chapters, 50 record pages, four review templates, 12 new synthetic examples and 24 authored review questions. - Added twenty bounded primary-portion-checked metrology records and nine source-page cards, preserving all six legacy entries and their labels.
- Adopted the same common record/node/relationship contract as the other Forge nodes. Standalone reference retrieval uses the shared Forge kernel.
- Repaired the scale-dependent covariance PSD validation defect: invalid small covariances no longer collapse to zero uncertainty.
- Added singular/indefinite/scaling/overflow regression cases and a 600-case optional NumPy arithmetic comparison.
- Added repeatable `as_of` traceability documentation checks and five explicitly synthetic worked examples.
- Measurement v1 remains incomplete; no next-domain advance, laboratory replication, live Bitwork integration or independent answer-quality benchmark is asserted.
