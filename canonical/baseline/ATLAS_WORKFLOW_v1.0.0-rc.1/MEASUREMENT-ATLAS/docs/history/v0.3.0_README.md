# MEASUREMENT ATLAS · v0.3.0

**The reference layer that helps every Atlas say what a measurement means.**

Part of the [ATLAS FORGE](https://chatgpt.com/space/page_4ea78e16086c8191bbf22f6407c29e2b) research ecosystem. This version expands the original v0.1 starter with testable, dependency-free numerical teaching utilities for Type A uncertainty of the mean, first-order covariance propagation, expanded uncertainty, and uncertainty-aware difference estimates.

## What is implemented

- Source-linked five-packet NIST table-of-contents navigation, preserved without promotion of evidence status.
- Type A standard uncertainty of the mean from repeated readings (sample standard deviation / sqrt(n)).
- Linearized uncertainty propagation using covariance and sensitivity coefficients, with PSD and symmetry checks.
- Expanded uncertainty, requiring an explicit coverage factor without automatically calling k=2 "95%".
- Difference uncertainty with optional covariance, with no ungrounded pass/fail decision rule.
- 15 direct numerical tests.

## Quick start

```powershell
py -3 -m measurement_atlas type-a "[10,12,14]"
py -3 -m measurement_atlas combine '{"sensitivities":[1,1],"covariance":[[4,0],[0,9]]}'
py -3 -m unittest discover -s tests -v
```

## Scientific boundary

These are verified implementations of **declared mathematical models**, not a calibration lab, a complete GUM interpreter, or independent reviews of third-party publications. For real decisions the user must justify independence, distribution assumptions, correlation, systematic sources, model linearity, coverage factor, and traceability. The source packets are headings-only editorial navigation until primary source passages are evaluated.
