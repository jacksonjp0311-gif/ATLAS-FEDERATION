# Accuracy is not a numerical uncertainty specification

**Record:** `accuracy-qualitative` · **Type:** concept · **Origin:** source_reported

Accuracy is a qualitative comparison with the quantity value sought. It is not interchangeable with precision or a numerical uncertainty budget.

## Source and inspected portion

[Measurement accuracy](https://jcgm.bipm.org/vim/en/2.13.html) · 2.13, notes 1–2

## Assumptions

- VIM3 terminology is being used.

## Limitations

- A manufacturer label such as accuracy ±x must be interpreted from its stated specification rather than treated as standard uncertainty.
