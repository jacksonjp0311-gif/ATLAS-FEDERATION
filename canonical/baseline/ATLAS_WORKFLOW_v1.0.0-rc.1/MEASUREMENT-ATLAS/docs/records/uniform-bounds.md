# Uniform bounded uncertainty

**Record:** `uniform-bounds` · **Type:** method · **Origin:** source_reported

For a symmetric uniform model with half-width a, the standard uncertainty is a divided by sqrt(3).

## Declared relation

```text
u = a/sqrt(3)
```

## Source and inspected portion

[Type B evaluation](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-4-type-b-evaluation-standard-uncertainty) · §4.6

## Assumptions

- Equal probability within justified symmetric bounds.

## Limitations

- Bounds alone do not establish a uniform distribution.
