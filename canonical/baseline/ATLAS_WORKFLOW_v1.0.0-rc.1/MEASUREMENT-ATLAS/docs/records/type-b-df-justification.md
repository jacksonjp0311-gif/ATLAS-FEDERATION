# Type B does not automatically mean infinite reliability

**ID:** `type-b-df-justification` · **Origin:** `source_reported` · Assistant source-portion check, not independent review.

An infinite degrees-of-freedom assignment for a Type B component needs a reliability justification. The toolkit requires the choice explicitly rather than inferring it from the Type B label.

## Assumptions

- The uncertainty estimate and its reliability have a defensible basis.

## Limitations

- Uncertain bounds or an unjustified distribution can invalidate the choice.
