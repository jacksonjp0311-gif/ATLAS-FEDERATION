# Error is not uncertainty

**Record:** `error-not-uncertainty` · **Type:** concept · **Origin:** source_reported

A result can have a small unknown error yet substantial uncertainty. Uncertainty is not the realized error.

## Source and inspected portion

[Classification of uncertainty components](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-2-classification-components-uncertainty) · §2.3 note

## Assumptions

- The stated model and source scope apply to the task.

## Limitations

- The true error is generally not known from an uncertainty estimate.
