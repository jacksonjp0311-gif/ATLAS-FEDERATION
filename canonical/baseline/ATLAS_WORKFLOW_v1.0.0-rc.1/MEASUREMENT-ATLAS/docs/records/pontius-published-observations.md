# Pontius published load-cell calibration observations

**Record:** `pontius-published-observations` · **Type:** dataset · **Origin:** source_reported

NIST publishes 40 deflection/load pairs from two increasing-load runs at 20 levels between 150000 and 300000 source load units. The Atlas includes a checked decimal-token transcription, not the original transport bytes.

## Source and inspected portion

[Pontius load-cell observations](https://www.itl.nist.gov/div898/handbook/datasets/PONTIUS.DAT) · Header and numeric table, all 40 rows

## Assumptions

- Row order and decimal values are preserved in measurement_atlas/resources/pontius/observations.json.

## Limitations

- Source load and response units, acquisition date, instrument serial and a calibration certificate are not given in the inspected material.
- This is reanalysis of source-reported observations, not new laboratory measurements.
- The capture hash identifies local normalized data, not a downloaded original NIST file.

Assistant source-portion inspection or explicit local derivation; no independent scientific review or physical replication.
