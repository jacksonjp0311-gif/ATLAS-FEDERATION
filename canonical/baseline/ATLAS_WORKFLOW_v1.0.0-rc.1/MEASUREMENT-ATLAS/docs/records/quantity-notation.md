# Write values and units without ambiguity

**Record:** `quantity-notation` · **Type:** method · **Origin:** source_reported

Write the unit with the numerical value; column headings can use a quantity divided by its unit. A space separates a value from °C.

## Source and inspected portion

[Reporting values and units](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-7-rules-and-style-conventions-expressing-values) · §§7.1–7.2

## Assumptions

- SI reporting notation is used; plane-angle notation has specified exceptions.

## Limitations

- Formatting correctness alone does not validate a measurement.

Assistant source-portion inspection or explicit local derivation; no independent scientific review or physical replication.
