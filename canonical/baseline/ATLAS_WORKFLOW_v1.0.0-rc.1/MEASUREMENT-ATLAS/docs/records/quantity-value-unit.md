# A quantity value includes its unit

**Record:** `quantity-value-unit` · **Type:** concept · **Origin:** source_reported

A measurement value is represented by a numerical value and a unit; the stated absolute uncertainty uses that same unit.

## Declared relation

```text
Q = {Q}_u * u
```

## Source and inspected portion

[SI quantities, dimensions and units](https://www.nist.gov/pml/special-publication-330/sp-330-section-2) · §2.1

## Assumptions

- The quantity being reported is identified.

## Limitations

- Numerical values in different units cannot be compared directly.
