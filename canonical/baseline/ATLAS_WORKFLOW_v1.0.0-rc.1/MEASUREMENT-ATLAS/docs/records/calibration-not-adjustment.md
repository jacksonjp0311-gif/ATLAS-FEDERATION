# Calibration is not adjustment or verification

**Record:** `calibration-not-adjustment` · **Type:** concept · **Origin:** source_reported

Calibration, changing an instrument response, and checking requirements are distinct operations. Record separately which operation was performed.

## Source and inspected portion

[Calibration](https://jcgm.bipm.org/vim/en/2.39.html) · 2.39, note 2

## Assumptions

- Operation names are interpreted using VIM3.

## Limitations

- A calibration entry does not automatically mean an instrument was adjusted or passed a tolerance.
