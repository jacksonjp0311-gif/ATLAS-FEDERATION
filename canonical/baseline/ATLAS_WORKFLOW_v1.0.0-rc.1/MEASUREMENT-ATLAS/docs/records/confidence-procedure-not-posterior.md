# Frequentist coverage describes the procedure

**ID:** `confidence-procedure-not-posterior` · **Origin:** `source_reported` · Assistant source-portion check, not independent review.

A confidence coefficient describes the long-run fraction of intervals containing the fixed target under the model. It is not a posterior probability assigned to one realized interval.

## Assumptions

- Independent normally distributed errors with constant variance; applicability is supplied by the caller, not inferred from a passing calculation.

## Limitations

- A Bayesian credible probability requires a separate model and is not produced by this method.
