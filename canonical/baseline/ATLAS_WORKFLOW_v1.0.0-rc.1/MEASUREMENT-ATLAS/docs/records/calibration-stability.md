# Calibration must remain applicable over time

**Record:** `calibration-stability` · **Type:** concept · **Origin:** source_reported

Drift or day-specific changes can invalidate a calibration relationship. Aggregated data may hide differences visible when measurements are examined by day.

## Source and inspected portion

[Calibration failure modes](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc364.htm) · §2.3.6.4, Lack of system control and day-to-day differences

## Assumptions

- Repeated checks concern the same specified response regime.

## Limitations

- A certificate date alone does not establish current statistical control.
