# Specify the measurand before calculating

**Record:** `measurand-definition` · **Type:** concept · **Origin:** source_reported

Identify the intended quantity together with the object, state and relevant conditions; a number and an instrument name do not fully specify a measurand.

## Source and inspected portion

[Measurand and measurement intervention](https://jcgm.bipm.org/vim/en/2.3.html) · 2.3, definition and note 1

## Assumptions

- The intended use and object are specified.

## Limitations

- A different condition may define a different measurand, not a repeat of the same measurement.

Assistant source-portion inspection or explicit local derivation; no independent scientific review or physical replication.
