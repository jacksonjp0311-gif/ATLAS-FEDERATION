# Inverse calibration needs an admissible domain

**Record:** `inverse-root-domain` · **Type:** method · **Origin:** source_reported

The quadratic inverse in the Pontius illustration has more than one mathematical root. The source restricts the usable solution to the measured load range; the distant root is not a valid calibration result.

## Assumptions

- The chosen branch is monotone and identifies a unique in-range solution.
