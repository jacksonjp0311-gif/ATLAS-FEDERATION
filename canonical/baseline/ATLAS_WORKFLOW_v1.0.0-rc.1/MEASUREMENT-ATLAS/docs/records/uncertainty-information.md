# Uncertainty belongs to the result and information used

**Record:** `uncertainty-information` · **Type:** concept · **Origin:** source_reported

Measurement uncertainty characterizes the dispersion assigned to a result using available information, including appropriate systematic-effect and reference-value components.

## Source and inspected portion

[Measurement uncertainty](https://jcgm.bipm.org/vim/en/2.26.html) · 2.26, definition and notes 1–4

## Assumptions

- The measurement model and information set are explicit.

## Limitations

- Repeated-reading scatter is only one potential component.

Assistant source-portion inspection or explicit local derivation; no independent scientific review or physical replication.
