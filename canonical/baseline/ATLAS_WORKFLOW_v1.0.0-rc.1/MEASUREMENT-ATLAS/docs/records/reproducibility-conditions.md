# Reproducibility conditions

**Record:** `reproducibility-conditions` · **Type:** concept · **Origin:** source_reported

A reproducibility study declares which locations, operators, systems or procedures differ and which conditions remain fixed.

## Source and inspected portion

[Reproducibility conditions](https://jcgm.bipm.org/vim/en/2.24.html) · 2.24, definition and note 2

## Assumptions

- The same or similar objects and a comparable measurand are used.

## Limitations

- Re-running a software script is not, by itself, metrological reproducibility.

Assistant source-portion inspection or explicit local derivation; no independent scientific review or physical replication.
