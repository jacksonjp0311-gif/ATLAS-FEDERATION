# Normal two-sided conformance probability

**Record:** `normal-conformance-two-sided` · **Type:** equation · **Origin:** source_reported

For a declared normal model, subtract normal cumulative probabilities at the standardized limits.

## Declared relation

```text
p_c = Phi((U-y)/u) - Phi((L-y)/u)
```

## Source and inspected portion

[Measurement uncertainty in conformity assessment](https://www.bipm.org/documents/20126/2071204/JCGM_106_2012_E.pdf/fe9537d2-e7d7-e146-5abb-2649c3450b25) · §7.4, equation (11), printed p.16

## Assumptions

- Normal state-of-knowledge model, u > 0, same quantity and units.
