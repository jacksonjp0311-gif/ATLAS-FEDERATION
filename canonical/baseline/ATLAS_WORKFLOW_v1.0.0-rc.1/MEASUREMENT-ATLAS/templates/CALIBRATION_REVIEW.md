# Calibration record review template

**Status:** documentary review aid, not accreditation or certification.

Record certificate issuer/identifier, instrument identity, reference quantities, range, points, applicable conditions, correction/function, uncertainty type, stated k/probability, coefficient covariance if relevant, calibration date, subsequent changes and ongoing checks. Link original files and record their integrity hashes separately from authenticity review.

Outcome: usable within stated conditions / evidence incomplete / mismatch identified.

Explain every outcome. A date or unbroken link chain alone does not demonstrate that the actual current measurement is traceable or fit for purpose.
