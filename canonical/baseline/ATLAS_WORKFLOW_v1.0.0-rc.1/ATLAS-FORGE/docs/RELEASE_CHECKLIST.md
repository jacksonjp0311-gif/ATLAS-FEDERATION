# Release checklist

- [ ] Domain scope and exclusions are explicit.
- [ ] Primary source identities, accessed versions and rights reviewed.
- [ ] Source claim evidence portion/locator retained; uncertainty recorded.
- [ ] No simulation or source summary mislabeled as experimentally reproduced.
- [ ] JSONL packets validate and count matches manifest.
- [ ] Historical exports/corrections preserved when upgrading existing Atlas.
- [ ] Negative/unanswerable queries abstain.
- [ ] Agent interfaces keep citations and limitations.
- [ ] Independent evaluation compared against strong baseline, or marked pending.
- [ ] README hero and index correspond to files in release.
- [ ] Local tests, installed CLI, and integrity manifest verified.
- [ ] Release rights and license decisions documented.
- [ ] GitHub remote commit, tag, published assets actually checked before reporting publication.
