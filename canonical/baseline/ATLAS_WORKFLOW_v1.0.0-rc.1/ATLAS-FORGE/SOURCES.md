# Starting-source directory

Use these for source discovery and attribution, **not** as preverified imported data. Respect each publication's licenses and versioning.

- **Measurement Atlas:** [NIST TN 1297; SI Brochure](https://www.nist.gov/pml/nist-technical-note-1297)
- **Causal Atlas:** [Hernán and Robins, Causal Inference: What If](https://miguelhernan.org/whatifbook)
- **Materials Atlas:** [Materials Project property documentation](https://docs.materialsproject.org/)
- **Control Atlas:** [Åström and Murray, Feedback Systems](https://authors.library.caltech.edu/records/yzs24-xsx88)
- **Agent Atlas:** [Published agent engineering practices; open-source frameworks](https://www.anthropic.com/research/building-effective-agents)
- **Computation Atlas:** [NIST DLMF and validated numerical references](https://dlmf.nist.gov/)
- **Language Atlas:** [Universal Dependencies](https://universaldependencies.org/introduction.html)
- **Energy Atlas:** [US DOE open data](https://www.energy.gov/data/open-energy-data)
- **Bioelectric Atlas:** [Peer-reviewed bioelectric regeneration research](https://pubmed.ncbi.nlm.nih.gov/30799071/)
- **Manufacturing Atlas:** [NIST Smart Manufacturing Systems Test Bed](https://www.nist.gov/laboratories/tools-instruments/smart-manufacturing-systems-sms-test-bed)
