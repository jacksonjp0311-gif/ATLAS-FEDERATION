# 54. Pragmatics, speech acts, implicature and situated communication

Semantics provides one account of linguistic meaning; pragmatics studies how utterances are used by people in contexts. “Can you open the door?” has an interrogative grammatical form but often functions as a request. This inference depends on speaker intention, relationship, institutional setting, gesture, common ground and expected consequences. A grammar that classifies it as a question has not completed its communicative interpretation. A rule that always commands a tool to open a door would be worse: interpreting a request is not the same as being authorized to take an external action.

## Reconstruction

Represent a communicative event as an utterance with participants, time/place, shared context, possible intentions, observable responses and consent. Distinguish the *literal proposition*, conversational implicatures, presuppositions, indirect speech acts, deictic reference (I, here, now), and multimodal cues. If a presumed referent is missing, retain alternative readings or an unresolved reference rather than inventing one. A speaker can deliberately be ironic, use figurative language, or communicate by gesture; word meanings alone cannot determine the outcome.

A useful thought experiment contrasts “The room is cold” stated as a weather observation and as a request to close a window. The string is identical; the action inference changes with context. To study it, document contextual manipulations and ask speakers what interpretations are plausible. Do not re-label the experiment as completed unless actual people gave informed consent and the original responses were collected.

## Failure boundary

Pragmatic inference is not a license to override user intent. In an AI agent, any inferred command must still pass the host's explicit permissions and tool-side-effect safeguards. The Atlas stores conceptual and computational reference material only. Its finite semantic truth checker cannot test conversational implicatures, politeness, irony or speaker intent. Those remain substantive research and future evaluation requirements.
