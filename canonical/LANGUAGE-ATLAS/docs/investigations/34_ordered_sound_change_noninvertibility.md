# Investigation 34 — Ordering rules can change reconstructed outputs

A two-stage constructed phonological model changes p→f before a and t→s after a in [p,a,t], producing [f,a,s]. Every stage records input/output and positions changed. Reversing context-sensitive rules can produce a different result, illustrating why chronology and representation choices matter.

A sequence of formal replacements is not proof that any historical language evolved this way; the output can be consistent with more than one ancestry. If two rules merge distinct inputs into one form, inversion cannot uniquely reconstruct the source. Preserve irregularities rather than adjusting the rules to fit each example after seeing all results.

No original recordings, inscriptions or comparative language dataset were used.
