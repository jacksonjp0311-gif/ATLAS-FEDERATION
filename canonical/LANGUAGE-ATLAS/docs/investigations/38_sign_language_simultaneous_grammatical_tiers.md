# Investigation 38 — An overlapping facial marker is not an error

A constructed signed-language annotation has manual activity from 0–250 ms and a facial tier from 100–200 ms. These intervals overlap because the tiers represent simultaneous channels of potential language expression. Rejecting overlap globally would remove valid multimodal structure. Checking time metadata does not authenticate sign glosses or the underlying recording.

The reference preserves tier, start/end time, unknown clock accuracy and source rights. It has not acquired authentic signed-language media or fluent-signer evaluations. Reproducibility of the interval check should not be described as verified linguistic interpretation.
