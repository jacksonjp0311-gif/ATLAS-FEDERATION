# Investigation 40 — Can the language evidence survive the loss of its publisher?

A future researcher opens the offline Language Atlas and reconstructs an NFA, a quantified relation, a segment edit table and a rights-aware accession packet without network access. The original manuals and Python methods support those *educational calculations*. But the official Unicode 18 property tables, public UD datasets, signed-language videos and community field recordings are missing.

The correct survival audit reports **source debt**, not “the language is fully preserved.” A complete future archive would need source bytes with clear rights, community access restrictions, versioned grammars and dictionaries, data dictionaries, annotations, recordings where permitted, multiple storage copies and successful offline restoration trials.

This exercise establishes what the offline reference teaches and which essential empirical evidence it lacks. It does not claim to speak, translate or understand all human languages.
