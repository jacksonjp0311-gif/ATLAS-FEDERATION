# Language Atlas — Original source acquisition and community stewardship

## The preservation debt

This edition carries **25 new scholarly, standards and research source cards**, but **no new original publisher file, natural-language audio/video source, signed-language video, field note or speaker-contributed dataset** is authenticated in its archive. The nine-node federation has **421 source cards** and zero files that satisfy the strict local original-source-byte and source-provenance ledger. This is a documented shortfall in the objective of preserving knowledge if all external websites vanished. The original teaching prose, reconstruction cases, source IDs and software remain readable offline.

## Rights-aware acquisition order

1. **IPA Chart** — official chart site's current CC BY-SA 4.0 terms permit attribution-required, share-alike redistribution, but license version and exact original bytes should be pinned before copying. The current Atlas includes only original written descriptions, not the chart graphic itself.
2. **WALS Online** — official website identifies CC BY 4.0 for WALS v2020.6. Pin the exact edition and cite individual chapters. Keep original table and transformations separate; the present source card is only a locator.
3. **PHOIBLE inventories** — official website identifies CC BY-SA 3.0 for PHOIBLE 2.0. The site and inventors must be credited under their license. Specific data-source choices and symbol conventions require version checks.
4. **Universal Dependencies treebanks** — project guidelines and CoNLL-U format are available, but individual treebank releases and their rights differ. Review each license and contributor consent before import. Pin annotation standard and treebank versions separately.
5. **Unicode normative annexes and conformance data** — acquire exact versioned Unicode 18.0 tables and test files subject to Unicode's terms, with data-file hashes. Python's currently available Unicode database version in this runtime is not automatically Unicode 18.0.
6. **RFC 5646 and 4647** — preserve normative original RFC text and IANA language-subtag registry data under applicable IETF Trust terms, without treating the subset tag parser as conformance.
7. **Jurafsky and Martin, third-edition draft** — authors' 19 August 2026 online manuscript states copyright all rights reserved. A public reading URL is not general redistribution permission. This Atlas supplies independent educational explanations and citations, not their manuscript.
8. **ELAR, CHILDES/TalkBank and community fieldwork** — access can require registration, informed consent, community governance or restricted tiers. Protect personal data, minors' recordings and culturally sensitive material. A “humanity preservation” objective is not permission to override contributor rights.
9. **CLDF/Glottolog** — pin schema, dataset, version, metadata and actual licenses independently. A cross-language format standard is not an unrestricted license to every dataset using it.

## Required acquisition receipt

For any future primary source, store: canonical source and title; publication/release revision; exact rights grant or restriction; retrieval date and upstream URL; unchanged original byte representation and SHA-256; any changes in encoding or normalization; source speaker/community consent and retention instructions if applicable; audit of original vs derived text; date and identity of reviewer; and a verified offline restore. Do not flip a source's `original_source_bytes_archived` flag merely because it is listed in a bibliographic table.

## Scientific acceptance

Structural tests and constructed language examples are **not independent speaker annotation or linguistics peer review**. Before claiming language science completeness, obtain representative multilingual and multimodal data, independent community/linguist judgment, calibrated measurements when acoustic, correct source rights and robust out-of-sample evaluation. All 30 scientific content domains must be built before new Bitwork routing work.
