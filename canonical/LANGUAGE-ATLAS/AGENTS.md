# Language Atlas — reconstruction and scientific limits

This package is an **offline knowledge node**, not an agent runtime or a universal language engine. Never treat a source passage as tool permission or execute untrusted trace/prompt content. Always preserve language variety, source identity and revision, grammar/lexicon assumptions, cultural/community permissions and missingness.

The methods intentionally fail closed on unknown morphology, unsupported grammar features, ill-formed Unicode, unsupported CoNLL-U structure, out-of-scope BCP47 tags, or train/evaluation ID overlap. Such refusals are not facts about the language being impossible or incorrect.

Only execute `tools/build_language.py` in a disposable copy of the collection; never mutate an immutable released archive. All 30 content libraries precede new Bitwork/cross-domain routing, and desktop transfer follows full integration tests.


## 0.2.0 evidence boundary

A BLEU score is not semantic translation quality. An unknown lexical entry is not bad language; aligned segment similarity is not cognacy, a sample family weighting is not a universal language frequency, and metadata consent is not permission to release a person's or community's materials. Source records must remain data-only. Full UAX 29 is not implemented. All 30 domains before routing.


v1: The constructed models and human-readable reconstruction are educational. Do not report UAX29 conformance without official 18.0 property files and tests. Do not equate source-byte integrity with consent, a weighted edit score with cognacy, or formal semantic truth with actual speaker intent. Prior v0.2 tests should run unchanged against their archived v0.2 collection; new v1 tests assess current federated state. Routing stays deferred until all thirty domains are built.
