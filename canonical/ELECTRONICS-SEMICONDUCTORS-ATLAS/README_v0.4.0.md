**Not a new Atlas.** Builds on exact verified Electronics v0.3.0, while retaining the original Mathematics & Physics 1.0.0-rc.1 evidence status and all historical editions.

New models: voltage noise margins, DAG delay envelopes, setup/hold and clock skew, empirical metastability MTBF boundaries, NAND-based word ALU, memory read/write collision semantics, four-phase handshakes and RC uncertainty propagation.

All work is **finite numerical/reference research**. Sources are bibliographic links, not locally authenticated publisher originals; no fabricated CPU or silicon device is claimed. The original thirty-domain queue is unchanged and Bitwork routing stays deferred until knowledge-domain completion.
