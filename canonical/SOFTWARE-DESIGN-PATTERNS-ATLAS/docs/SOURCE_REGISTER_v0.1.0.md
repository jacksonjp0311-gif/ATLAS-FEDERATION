## Authentication process before scientific or safety promotion

When licensed original publisher documents are lawfully obtained, record final URL, original bytes and SHA-256, edition and date, source-specific license/rights, relevant page/section, tested claim, independent reviewer and any contradictions. A URL, generated digest, and a software test do not independently establish source authenticity or physical device reliability.
