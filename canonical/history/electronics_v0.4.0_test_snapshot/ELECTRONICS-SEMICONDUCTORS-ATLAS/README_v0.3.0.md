# ATLAS FORGE — Electronics & Semiconductors v0.3.0

**One versioned scientific node inside the original 13-node canonical federation.** Not a separate system or replacement library.

The latest work adds Chapters 19–26: nodal RC transient balance, capacitive dynamic energy, NAND arithmetic, clocked register uncertainty, setup/hold timing, Hamming SECDED, register banks and the Computer Architecture handoff. Standard-library kernels are in `electronics_atlas/v03_models.py`, with tests in `tests/test_v03_models.py`, and optional independent NumPy-based evidence in `evidence/independent_oracle_v03.py`.

All original 18 chapters and previous tests remain present; release snapshots are immutable. Software validation does not constitute device measurement, fabrication or scientific peer review. Further work goes to Manufacturing and Computer Architecture nodes under the **unchanged original 30-domain program**; routing later.
