## Reproduce without cloud providers

```bash
python -m energy_atlas casebook
python -m energy_atlas survival-casebook
python -m energy_atlas v1-casebook
python -m unittest discover -s tests -q
python tools/v1_oracle.py        # optional NumPy
```

The pure-Python models calculate hypothetical energy and service ledgers, not physical installation instructions. They distinguish a Watt from a Watt-hour, model conversion losses, reject impossible battery states, and report critical demand that cannot be served. Fields are not real measurements. No battery, generator, power system, contaminated-water treatment or medical device is approved by these functions.
