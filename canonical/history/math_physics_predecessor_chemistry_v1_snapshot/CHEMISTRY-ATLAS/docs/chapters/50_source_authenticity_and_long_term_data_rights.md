# 50. Source authenticity and long-term data rights

**Field:** Scientific continuity · **Version:** v0.2.0 · **Scientific status:** original educational reference; cited publisher portions inspected, original publisher bytes not archived. No real experiment.

## Principles and physical scope

The goal of technological continuity requires more than references that break when a website disappears. Each high-value source should be preserved in rights-cleared original bytes with a trusted publisher identity, retrieval date, edition, SHA-256, and a reproducible transformation trail. A hash alone proves only equality to an expected digest; both the file and its expected digest can be fabricated. A true provenance record distinguishes the local calculation, an official publisher document, a licensed scientific database, and independently replicated experimental evidence. Research ethics and institutional copyright must remain enforced; openness of a metadata page does not necessarily make the full dataset or compiled reference work freely redistributable.

## Equation and definitions

`SHA256(raw_bytes)=expected_hash is a byte-integrity condition, not a proof of publisher identity or reuse authorization. Evidence maturity must retain independent rights and review fields.`

Inputs and reference states must be declared. The algebra alone cannot establish source data validity, experimental behavior or physical safety.

## Derivation and why the relationship holds

An accession procedure should verify the publisher URL or DOI, exact original file bytes, usage terms, and source version before claiming local primary material. Only then should the archive record byte-fixity from a trusted expected digest and compare independent source copies where possible. The local `source_bytes_audit` refuses to call a matching hash “authenticated publisher source” and never automatically permits republication. The package's previous source-card metadata remains immutable, even if a new source record later provides stronger evidence.
