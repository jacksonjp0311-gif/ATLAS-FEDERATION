# Chemistry Atlas — Version path and global priority

**Current milestone:** original readable science and reference models, no original publisher-file accession or independent chemical experiments. v0.1.0 is deliberately not a scoped v1 content acceptance.

**Next Chemistry content edition:** more robust element/isotope data provenance, exact charge-balanced ionic reaction algebra, unit-aware thermochemical tables, phase/temperature ranges, bounded electrochemical models, stoichiometric networks, scientific instrument calibration, polymer distributions and semiconductor interfaces. Every new mathematical method must include an independent oracle or falsifying example and preserve unknown input values.

**Scoped v1 gate:** a human with no AI provider can read the complete method, reproduce examples offline, understand source evidence and licensing, identify a false application, and explain how the result would be tested experimentally. Scientific peer review and real manufacturing capability are separate gates that remain open until genuine experiments and technical authorities are involved.

**Technological Continuity Priority Directive v2.0:** The next high-leverage areas are Mathematics & Fundamental Physics, Electronics & Semiconductors, Manufacturing, Computer Architecture, Supply Chains, Compilers, Neural Architectures, OS Internals and Software Patterns. This can be revised as dependencies emerge and does not delete the existing 30 domain slots or prior released nodes. Bitwork routing comes after the collection's content phase, integration tests and user-computer transfer after routing.
