# Agent Atlas research protocols and evidence forms

## Agent execution trace

Goal and explicit testable end-state predicate / parent run ID / model/version / task IDs and prerequisites / approved capabilities/resources / event actor+action / tool request IDs / arguments hash and consent status / provider result / observed state and timing / cost and latency / recovery decisions / terminal actor+command / source/data licenses / missing evidence / operator review.

## Memory admission and knowledge correction

Memory ID and exact version / source run and task / observation vs inference / timestamp and time base / raw evidence receipt / qualifier and uncertainty type / contradiction references / token cost / selection rule and excluded units / correction and retention policy / secrets/redaction policy / review status.

## Failure incident and Bug2Eval protocol

Initial symptom / earliest divergent event / expected vs actual transition / affected user and resource / actor / dependency graph / hypotheses and counterevidence / reproduction fixture / exact regression test including negative case / repair revision / rollback plan / remaining ambiguities / independent review.

## Agent benchmark and end-state evaluation

Target task distribution / environment and tool versions / seeded task split and contamination analysis / objective/score and ground-truth end state / user simulator status / model settings / per-task run traces and interventions / pass-all-k vs pass-any-k / cost and wall-time / error categories / confidence method / limitations and unexplored tasks.

## Host tool safety review

Authenticated host catalog / capability and resource scope / approval receipt / data exposure/privacy policy / side-effect and idempotency contract / tampering threat model / read-after-write verification / transaction and rollback semantics / negative malicious-input tests / emergency Stop controls.

## v0.3 — authentic trace ingestion and experimental protocol

**Source and rights:** dataset owner, license and version pinned, raw byte hash or explicit null, source row IDs, access date, permitted use, sensitive content screening.

**OTel capture:** span IDs and parent lineage, instrumentation status/version, timestamp clock basis, dropped-span/sampling records, allowlisted metadata, scrubbing method, no unapproved content fields.

**External effect:** authorized task/request ID, provider idempotency contract, submitted/unknown/confirmed state, reconciliation query, receipt and independent outcome checker.

**Benchmark:** predeclared task population, baseline/candidate model versions, exact evaluator and task hashes, complete paired trial indices, sampling/seed plan, splits and leakage review, primary success and cost, negative results and independent verification.

**MAST labels:** framework/model/benchmark composition, 14-code mode version, LLM judge provenance, null denominators; human annotation revisions handled separately.

**Release gate:** source closure, previous immutable revisions, clean install, full collection tests, extracted ZIP rerun, research-to-deployment claims unchanged.
