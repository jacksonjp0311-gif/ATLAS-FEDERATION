## Offline use (Python 3.10+)

```sh
python -m computation_atlas
python -m unittest discover -s tests -q
python tools/numerical_oracle.py  # optional NumPy, SciPy and NetworkX
```

The original reference models cover formal computability, finite verification, algorithms, exact fractions, probability and numerical limits. Advanced pure-Python code adds minimum spanning forests, maximum flow, exact linear systems, FFT/convolution, conditional concentration bounds, vector clocks and a clearly labeled JSON canonicalization subset. These are **not** hardware benchmarks, certified cryptographic implementations or general-purpose trusted theorem provers.

## Evidence and preservation boundaries

Published course pages and standards abstracts are linked only. **No original publisher primary-source file is archived locally under the strict survival audit.** A hash proves byte equality under a trusted expected digest, not author identity or scientific correctness. Written derivations and reference algorithms remain readable offline, but the primary-source acquisition debt is real.

**Fixed global sequence:** complete all 30 domain reference libraries; then build Bitwork-powered routing, benchmark the integrated collection and transfer to the desktop. No router, Windows installation, live agent or external provider was modified in this edition.
