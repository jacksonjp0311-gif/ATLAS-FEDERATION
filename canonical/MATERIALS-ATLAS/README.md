## Methods and checks

Run `python -m materials_atlas v1-cases`, `python -m materials_atlas published-hahn1` and `python -m materials_atlas expanded-cases`. Optional separate SciPy/NumPy oracle: `python tools/v1_numerical_oracle.py`. Runtime needs only Python standard library.

Includes **two source-scoped numerical reproductions**: 236 checked transcribed NIST Hahn1 observations (response multiplier not authenticated), and the published NIST WebBook copper solid Shomate fit (selected table rows, 298–1358 K). The NIST WebBook compilation displays a copyright statement, so only necessary numerical facts and original explanatory text are included, not its complete tables or pages. A NIST-hosted corrosion presentation's text was read; web screenshot access failed. No uninspected PDF pages or licensed standards are portrayed as fully reviewed.

Explicit bounded educational calculators include conduction, diffusion, thermodynamics, XRD, fracture/fatigue, corrosion, isothermal transformation, creep and a physical-assumption-gated weakest-link law. No new specimen observation, independently reviewed property certification, guaranteed failure forecast, native Windows run, live Bitwork route or AI answer evaluation is claimed.

**Sequencing:** all 30 domains first, routing/Bitwork last, then integrated validation and desktop transfer. Next content domain: Control Atlas. The approved artwork and other four nodes remain unchanged.
