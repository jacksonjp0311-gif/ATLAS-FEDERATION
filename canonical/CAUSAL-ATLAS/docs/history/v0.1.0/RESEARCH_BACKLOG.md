# Causal Atlas development backlog

The node is now built under the shared contract, but remains a focused 0.1.0 reference foundation. Continue expanding it before treating its domain scope as complete.

Next content priorities are intervention consistency and interference, randomized-design details, finite-sample uncertainty, sensitivity to unmeasured confounding, and reproducible externally sourced examples with explicit reuse rights. Broader identification, mediation and time-varying designs require their own bounded reference cases and tests. Do not relabel the existing binary model as a general solver.

Preserve the current authored test set as regression evidence. Future independent questions must be collected and frozen separately before performance evaluation. Human evidence review, real model-answer tests and native desktop checks remain unrun. Final release acceptance stays separate from permission to continue content-building.
