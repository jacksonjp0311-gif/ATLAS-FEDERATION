# Never-treated and not-yet-treated comparisons differ

Controls must be untreated at the comparison date under the assumed design; already treated cohorts are not interchangeable with untreated controls.

## Conditions

- Validly defined first-treatment dates

## Limitations

- Never-treated status can change the population to which the comparison applies
