# Derive signed compliance contributions

In the stipulated finite model, the assignment outcome contrast equals the complier contribution minus the defier contribution plus the direct assignment contribution.

## Equation

`DeltaY = pC*tauC - pF*tauF + gamma; DeltaD = pC-pF`

## Assumptions and limits

- Same type distribution in each Z arm; additive direct contribution.
- Potential types/values are specified, not recovered from real observations.
