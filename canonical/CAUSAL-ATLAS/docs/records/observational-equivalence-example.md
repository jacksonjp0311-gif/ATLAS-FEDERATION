# Identical observations can hide different interventions

**Record:** `causal-atlas:observational-equivalence-example`  
**Kind:** method  
**Evidence:** authored_mathematical_teaching_material

Model A sets A=U and Y=U with fair binary U. Model B sets A fair and Y=A. Both produce only observed pairs (0,0) and (1,1), each with mass one half. Setting A externally has effect zero in A and one in B. Observations alone do not distinguish these stipulated worlds.
