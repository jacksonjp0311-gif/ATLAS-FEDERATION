# Use separate variables for distinct times

**Record:** `causal-atlas:time-labelled-variables`  
**Kind:** method  
**Evidence:** authored_mathematical_teaching_material

An operator’s pre-change experience, post-change training and later performance are different objects. Our study template requires a time definition for each field so that a variable collected later is not silently used as baseline adjustment. This is an author-proposed review procedure, not an automated causal-graph validator.
