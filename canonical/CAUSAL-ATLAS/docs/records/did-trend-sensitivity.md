# Subtract an explicit untreated-trend scenario

**Record:** `causal-atlas:did-trend-sensitivity`  
**Kind:** equation  
**Evidence:** authored_mathematical_teaching_material

Let D be the observed two-group, two-period contrast and delta the assumed difference in untreated trends. Under that model the treated-group effect is D-delta. D=0.05 is compatible with -0.03 when delta=0.08. The same four observations cannot decide which counterfactual trend is correct.

## Formula

```text
ATT=D-delta
```
