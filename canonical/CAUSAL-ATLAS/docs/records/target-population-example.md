# Who is averaged over changes the question

**Record:** `causal-atlas:target-population-example`  
**Kind:** concept  
**Evidence:** authored_mathematical_teaching_material

When the stipulated effects are 0.10 for easy jobs and 0.40 for difficult jobs, an 80/20 mix has average effect 0.16 while a 20/80 mix has effect 0.34. Both follow from the same effects. Naming a population is part of specifying the target, not an optional label.
