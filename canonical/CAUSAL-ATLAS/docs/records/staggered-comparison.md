# Treatment timing changes valid comparison groups

**Record:** `causal-atlas:staggered-comparison`  
**Kind:** concept  
**Evidence:** primary_portion_checked_by_assistant

In staggered adoption, never-treated and not-yet-treated comparisons correspond to different explicit assumptions. Group-time targets should be specified before aggregation; a single generic before/after contrast is insufficient.
