# Survival-based inclusion changes the comparison

**Record:** `causal-atlas:survivor-restriction`  
**Kind:** concept  
**Evidence:** primary_portion_checked_by_assistant

Restricting analysis to people or units that remain observable after the strategy starts can create selection. Later eligibility is not automatically equivalent to the originally intended population.
