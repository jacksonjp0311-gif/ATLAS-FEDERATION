# Computer Architecture and Digital Hardware

> Supplementary publication guide for this public mirror. This guide is new; the versioned source files retain their original bytes and historical names.

Explore the federation's original **AT8 educational computer**: an instruction contract, arithmetic gates, assembler, execution models, boot simulations, and finite evidence. These are software reference models; they do not demonstrate a fabricated CPU, qualified electrical timing, authenticated secure boot, or independent scientific acceptance.
