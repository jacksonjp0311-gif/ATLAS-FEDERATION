# Reconstructible bridge: original Computer Architecture v0.2

Source-language text → bounded AST → deterministic byte image → (13,8) SECDED ROM → exact byte hash → atomic AT8 / four-stage retirement → output/input/RAM trace → manufacturing evidence audit.

The archived challenge compiles an original program into unchanged AT8 instructions, simulates a one-bit ROM storage error, recovers the correct ROM, verifies both execution models and compares the source evaluator. It stores 12 in RAM address 4 and outputs 15. All 12 physical evidence types remain unverified and the physical gate stays HOLD.

The next engineering layer is a more capable assembler/linker/compiler and a timed/gate-level implementation with independent physical measures. The original source-register entries remain navigational, not authenticated publisher originals.
