# Agent Atlas v1.0.0 — reference directory

**Goal → Observation → Authorized Action → Trace → Receipt → Independent Evaluation → Qualified Memory → Reusable Knowledge**.
Read a chapter, reproduce its model, review its counterexample, then check source scope. These are original scientific explanations and constructed numerical examples, not externally verified agent improvement.
