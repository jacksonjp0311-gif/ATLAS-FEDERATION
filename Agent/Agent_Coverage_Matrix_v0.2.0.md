# Agent Atlas v0.2.0 — Scope and empirical evidence gates

**This edition is research content under development, not live agent capability or scientific v1.0 acceptance.**

| Area | Built reference/model | Not established |
|---|---|---|
| Task planning and worker admission | DAG ordering, dependency failure blocking, cost-bounded admission | Real worker scheduling, execution concurrency, optimal makespan |
| Tool host authorization | Static trusted-catalog and per-request approval illustration | Authenticated broker, real MCP permission enforcement or prompt-injection-proof execution |
| Event/receipt lineage | In-memory journal with run IDs and admitted parent dispatch; local checksums | Signed durable crash replay, real process restart, provider-side idempotency |
| Nested agent traces | Span tree validation, time interval coverage, evidence pointer diagnostics | Instrumented real agent traces, true task outcomes, synchronized cross-host clocks |
| Submitted side effects | Outbox phase reconciliation with unknown/uncertain effects | Exactly-once guarantee, actual provider transaction state, safe automatic retry |
| Memory consistency | Exact structured claim comparison, source revision/qualifier retention and expiry listing | Semantic contradiction detection, retrieval accuracy, privacy/deletion system or weight-level learning |
| Repeated-trial reliability | pass-all/any metrics and paired binary discordance sign test | Independent task sampling, calibrated evaluator, real held-out tasks or claimed gain |
| Multi-agent failure annotation | Public 14-code MAST card schema with `null` preservation | Full 1,642 source traces actually downloaded, label audits, human failure-ground-truth validation |
| Cost/resource and optimization | Bounded supplied-cost calculations | Measured token/power/latency/quality improvement, deployment-time economic evaluation |
| Forge and cross-domain interoperability | Seventh source-scoped node under unchanged common contract | Build remaining 30 domains, Bitwork router, live downstream AI evaluation and desktop transfer |

No fabricated completeness percentage, scientific acceptance, or confirmed real-world agent failure rates is stated. Source cards describe inspected portions only. **All thirty domains first; routing last.**
