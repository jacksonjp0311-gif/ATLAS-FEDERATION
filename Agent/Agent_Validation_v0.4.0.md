# Agent Atlas v0.4.0 — scientific and software verification

**Status: tested scientific reference development, NOT Agent v1.0 and NOT independently confirmed improvement of a live agent.**

## Source scope

- 38 chapters and 24 original worked investigations across planning, memory, tool reliability, trace provenance, recovery, multi-agent taxonomy, and paired evaluation.
- 158 exact revision records including 30 source cards and 101 qualified relationships. All 128 previous Agent record revisions and 83 previous relationships retained.
- Public publisher abstracts and technical documentation linked, not mirrored. Full MAST 1,642-row dataset and 19-row human annotation file were NOT acquired; the card is CC BY 4.0 but no original rows are claimed used.

## Executed code verification

- **1,221 automated tests passed with zero skips** across seven suites (Forge 188, Measurement 218, Causal 233, Materials 122, Control 244, Agent 216). The entire Forge corpus has **1,209 records and 430 relations**.
- **6,000 separate NumPy/SciPy comparisons passed** on constructed fixtures (proof priority, paired binomial tail, annotation matrices and memory review). These are author-generated, not actual agent measurements.
- Common fast-compiled JSON schema validated all records, relationships, nodes and 19 assembled contexts, with bounded Draft 2020-12 samples and runtime source-closure verification; full Draft 2020-12 validation of every large context is not asserted.
- Fresh isolated wheel installation loaded all six package distributions with standalone Agent 158 records and a source-linked context query. The source tree was not imported.
- Preservation: **1,424 protected files** from previous release byte-identical, including **771 original baseline members**, plus exact earlier Agent record and relation revisions.

## Limitations

One matching SHA-256 string does not authenticate external artifact bytes, host signatures, evaluator independence or semantic task success. A small exact discordance p-value cannot establish an uncontaminated test set or improved model performance. Annotation agreement cannot turn a model-judge category into a verified outcome. Memory eligibility is not persistent memory admission. No live tools, original MAST traces, independent outcome adjudication, Bitwork evaluation, native Windows transfer or scientific peer-review occurred.
