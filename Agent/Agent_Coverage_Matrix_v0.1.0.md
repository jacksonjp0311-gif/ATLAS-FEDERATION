# Agent Atlas v0.1.0 — scope and maturity matrix

**This is a substantial research foundation, not a v1 complete domain or a functioning multi-agent platform.**

| Domain | Reference coverage and executable examples | Important uncompleted research |
|---|---|---|
| Agent vs workflow and POMDP-style observation | Source-linked concepts and observation/state distinction | Calibrated belief updates from real transitions; environment-grounded tasks |
| Tool APIs and host authority | Static synthetic capability gate with scopes/approvals | Authenticated host broker, real MCP conformance, adverse prompt injection tests, transaction effects |
| Dependency planning | DAG validation, critical-cost model, resource-budget admission | Dynamic real agents, optimal scheduling, latency measurements, worker resource contention |
| Durable event streams | In-memory SHA-256 event chain, explicit actor-command, terminal Stop | Disk persistence, external anchor/signatures, atomic transaction log, secure parent/child restart |
| Worker handoff and evidence | Task/child identity-bound local content receipt, nonterminal reconciliation candidate | Real crash replay, provider-side read-after-write, remote signatures/attestation |
| Memory/reflection | Qualifier-preserving token-budget illustration | Actual long-term retrieval quality and contradiction repair, privacy, forgetting, learned memory policy |
| Multi-agent coordination | Failure taxonomy, nonindependent agreement cautions | Genuine multi-model experiments, inter-agent messaging, conflict and cost studies |
| Repeated reliability evaluation | Empirical pass-all-k and pass-any-k fractions, iid warning | Real AgentBench/τ-bench/SWE-bench runs, independent held-out tasks, confidence estimation |
| Resource/cost improvements | Explicit objective and critical path limits | Measured tokens, latency, power/compute, learning curve and success/error tradeoffs |
| Observability and governance | Typed event receipt, source provenance and scope | Production OTel instrumentation, full risk assessment and audit retention |
| Atlas interoperability | Same generic Atlas Common Contract; data-only search and source closure | All-30 domain node completion, Bitwork routing, real downstream model evaluation, native Windows transfer |

**Acceptance:** current `content_ready=false`; independent scientific review absent. Earlier Measurement rc1 and Control rc1 scientific/host acceptance remain separately open. Future versions should add authentic rights-cleared agent traces and real held-out benchmarks before claiming substantive agent capability.
