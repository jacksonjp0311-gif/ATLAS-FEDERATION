# Path from Computation Atlas v0.2 to scoped v1 content

A passing test count is necessary for software release but insufficient for a knowledge-survival release. Do not advance to Language Atlas until Computation's declared content families have reproducible, rights-aware reference coverage.

**Gate A — Mathematical reconstruction:** extend source-grounded foundations in numerical linear algebra, randomness and derandomization, complexity reductions, computable representation, external-memory/parallel models, programming semantics and data integrity. Each important theorem gets definitions, proof obligations, counterexamples and hand calculation.

**Gate B — Executable confidence:** complete adversarial and independent-oracle cases on algorithm families, enforce exact failure semantics, preserve random seeds and resource limits. Tests cover the model—not all real-world outcomes.

**Gate C — Authenticated primary sources:** seek permissioned, edition-pinned original bytes for core public/open sources, with SHA256, author/publisher, rights, acquisition timestamp and content scope. A URL does not survive publisher disappearance. Only upgrade evidence grade when bytes and rights have genuinely been recorded.

**Gate D — Source-to-claim review:** separate author-drafted derivations from publisher findings and independently audit selected high-impact claims, numerical stability requirements, and counterexamples. Record disagreements without overwriting prior records.

**Gate E — Release reproducibility:** full package and standalone ZIP fixity, clean offline wheel install, source-closed contexts, old revision checks, archive extraction replay, complete human restoration instructions and explicit defects list.

The content package can reach scoped v1 under those gates while remaining honest about missing independent experiments and deployed-system acceptance. Finish all 30 domains before Bitwork routing and desktop transfer.
