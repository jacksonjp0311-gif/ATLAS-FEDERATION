## Knowledge survival and source access

The federation contains **396 bibliographic source cards**, and the strict evidence audit recognizes **zero authenticated locally preserved original primary-source files**. The manual remains offline readable because its explanations, examples and algorithms are original; this is not equivalent to preserving the original publications. The six new source cards cover MIT algorithms and linear algebra, Lamport's 1978 clocks paper, Python decimal, AWS idempotency and NIST FIPS 203. Copyright, edition and errata must be checked before new full-text preservation.

## Scientific and deployment claims deliberately absent

No independent expert review, real task benchmark, field calibration, original publisher corpus mirror, new cryptographic implementation, ML-KEM conformance, authenticated host-signature verification, live agent run, actual Bitwork router, data movement to the user's computer or measured energy efficiency. Conditional statistical bounds require independent sampling; a model-judge label is not truth.

## Release procedure

Run `python tools/check_manifest.py verify .` and `python tools/survival_audit.py --check-files` from the extracted collection; run `python tools/check_collection.py --out /outside/new/unique/path`; install the pinned wheels offline and verify the standalone package, then compare archived SHA256 against the separately stored release receipt. An extracted-archive replay receipt is issued separately after actual execution.
