# ATLAS FORGE — scientific trust and evidence boundaries

**What can be defended today:** archive byte integrity, exact-revision graph consistency, reproducible finite numerical/software tests, and the observed behavior of the AT8 educational computer model.

**What cannot be defended yet:** that every external citation is authentic to original publisher bytes; that each physical equation has independent expert sign-off; that any physical machine or semiconductor has been reproduced; or that the complete original thirty-domain program has been finished.

## Gate ledger

| Evidence type | Requirement | Current status |
|---|---|---|
| Local file integrity | Expected SHA-256 from independently retained release receipt | Tested on this edition |
| Graph identity and referential integrity | Canonical JSON revision digest, exact record endpoint revision, source card identity | Tested on this edition |
| Human access | Browser-readable entrypoint, original Markdown manuals, standalone Python retrieval | Present; test on clean offline device |
| Peer review | Documented qualified independent author/reviewer, critique and signature over specific digest | **HOLD** |
| Original publisher sources | Real transport bytes, rights, published edition, hashes and precise formula locators | **HOLD** |
| Physical device data | Calibrated instrument trace, process/material provenance, uncertainty, adverse results | **HOLD** |
| Fabricated processor | Reproducible build and measured execution against golden model | **HOLD** |
| Cryptographic trust | Signed keys, independent signature validation, key custody and revocation | **HOLD** |
| Domain completion | Original thirty-domain roadmap completed | **HOLD** |

## Limitations that cannot be solved by more synthetic tests

Model assumptions may be wrong or out of regime. Source cards may identify an official website while omitting the original text, complete formula, or redistribution license. Inferred material constants cannot substitute for measured properties. A Python parity test cannot estimate silicon error rates. A checksum can be reproduced for malicious bytes. A code graph can be syntactically valid without being physically implementable.

When evidence is absent, preserve that absence as data. Do not fill it with fabricated measurements, claimed review signatures or implied scientific certainty. Safety-critical and regulated decisions require qualified professionals and locally applicable standards.
