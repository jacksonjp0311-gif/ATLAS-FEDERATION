# Recovery readiness is a testable claim

A valid backup must survive clean offline assembly, independently verified hashes, a complete file manifest, exact record revision checks, deterministic historic tests, and a fixed software reconstruction example. Metrics must be reported as observed outcomes, not promised results. A surviving file is not evidence that a practical technology can be safely rebuilt from it.
