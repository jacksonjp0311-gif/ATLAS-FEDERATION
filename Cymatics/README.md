# Cymatics — preserved federation reference

> Supplementary publication guide for this public mirror. This guide is new; the reference files below retain their original bytes.

This directory preserves the **Cymatics reference subset inside the original federation**. It contains scientific records, a frozen reference snapshot, and historical context receipts. It is not a complete standalone upstream application or a new physical experiment.

The [publication manifest](../evidence/publication/four-domains-2026-11-20-manifest.json) identifies original archive locations, hashes, and any holds. Historical receipts describe their own full-federation context; they are not fresh checks of this subset. Source-specific rights, missing evidence, and experimental limitations remain attached to the records.
