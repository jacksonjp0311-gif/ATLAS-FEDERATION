# Compiler Design original domain #18 · v0.1.0 scientific / operational HOLD

The Atlas federation v0.1 reference includes a real, executable, finite compiler pipeline. The following remain outside the verified scope and must not be represented as delivered capabilities:

- Real native machine code generation for any target (RISC-V, x86, ARM) or actual Wasm binary conformance
- A complete LLVM IR or C frontend, memory effects, arbitrary control flow, function calls or registers
- Formal semantic preservation proof covering all source programs
- Fully independent lexer/parser implementation for the oracle; both interpreter and code generator share the original parser
- Fault and security testing across hostile execution environments, signed publisher-original documents or independently qualified expert review
- Physical chip/compiler integration, independent cross-host byte reproduction or long-term storage durability

The initial v0.1.0 is intended to progress to v0.2.0 with substantive improvements such as second backend, stronger parser independence and SSA/CFG proof obligations. No arbitrary count or premature scoped v1 promotion.

No Bitwork routing or desktop transfer. Original 30-domain queue unchanged. Existing 23-node science records remain unchanged, except explicitly authorized common integration files.
