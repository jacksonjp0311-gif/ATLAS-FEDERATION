# ATLAS FORGE — READ THIS FIRST IF THE PROJECT IS INTERRUPTED

**A survival-preservation index, not an operational emergency-response manual.** The user-directed goal is to preserve enough truthful, reconstructible human knowledge that others can learn and rebuild even if external websites and AI services are unavailable. This document does **not** certify that the collection can presently fulfill that goal.

## What is missing and must not be falsely presented as ready

The original 30-domain roadmap currently lacks standalone scientific domains for safe water/sanitation, public health and essential medicine, food/agriculture/nutrition, shelter/construction, applied chemistry, and ecological biology. These are in the survival-first directive as *priority seed workstreams*, not falsely counted as completed knowledge nodes. The ten existing nodes offer partial foundational context but do not replace those missing disciplines.

## If construction stops after the next release

A useful minimum package for each priority subject should include: a plain-text human lesson that does not require a cloud model; a glossary and exact units; a small verified method or calculation; what cannot be concluded from it; common hazards and abstention conditions; source bibliographic facts and rights; available original primary-source bytes when lawfully retained, with SHA-256 and licensing; and an offline restoration exercise. The program must not postpone this essential coverage merely to expand earlier reference texts from 50 to 70 chapters.

**A real expert or authorized body must review safety-critical procedures before a field-use label is applied.** Water, electrical, clinical, structural, food-safety and chemical operating instructions must never be marketed as safe solely because a numerical program passes.

## The single biggest documentary failure to fix

The current checkpoint reports **466 bibliographic source cards and zero original primary-source files authenticated by the strict local byte-provenance audit**. This means important published works may be absent if the network disappears. Source acquisition is therefore a **priority-zero workstream independent of the next scientific domain**. Obtain primary texts under a verified license; retain publisher, version, retrieval timestamp, exact bytes and hash; maintain read-only copies and test restoration. Do not copy restricted text without permission.
