# Language Atlas — Primary Source and Community Rights Preservation Plan

**Purpose:** reduce the archival vulnerability that currently leaves 429 bibliographic source cards without authenticated original source bytes. Preserve human knowledge without equating internet links, text models or permission metadata with a lawful complete archive.

## Immediate authentic-source acquisition priorities

1. **Unicode 18 UAX #29 conformance data**: official Unicode data files such as `GraphemeBreakTest.txt`, under Unicode License v3 where the specific file is covered. The original attempt to download these bytes in the release sandbox failed. Do not claim they were acquired, verified or evaluated. Reattempt under an authorized network-access environment, archive the exact unmodified file, copy full license notice, compute SHA-256 and pin the Unicode revision/commit. The standard's prose itself may have different distribution terms from data files.
2. **WALS version-pinned typological data**: confirm chapter/data edition and CC BY attribution, preserve CSV/raw release and documented source fields, avoid multiplying apparent independent observations from the same family. Record original authors, classification revisions and missing/ambiguous values.
3. **CLDF specification plus rights-cleared exemplar datasets**: verify the exact schema version, CSVW metadata and BibTeX source chain, original bytes and license. CLDF conformance alone does not grant rights to included recordings.
4. **UD treebanks and language corpora**: check every treebank license separately, including source text permissions, access conditions and contributor citations. Record CoNLL-U features, enhanced dependencies, multiword tokens and empty nodes with version-specific validators before claiming completeness.
5. **IPA and signed-language instruction**: obtain and preserve the properly attributed official IPA resources only within their declared license. For signed language content, obtain qualified community-reviewed materials and consent where required; otherwise retain only public high-level descriptions and bibliographic metadata.
6. **Endangered-language recordings**: use community/speaker-approved access procedures through ELAR, California Language Archive or comparable repositories. Restriction, correction and revocation are part of archival integrity; restricted material must not be published into a public knowledge ZIP merely to increase source counts.

## Accept a source only when all conditions hold

Source/edition identifier; direct publisher acquisition; exact source bytes when redistribution rights permit; immutable SHA-256; license and attribution; retrieval date; transformation and normalization history; language/dialect/context metadata; speaker and community permissions as relevant; format decoder or schema; independent source inspection; and archive restoration test. A digest string alone is not evidence of possession or authenticity.

## Reproduction before scope expansion

Use a fresh offline environment to inspect archive contents, compare raw bytes and manifests, run normative Unicode test vectors under a versioned segmentation engine, check CLDF/UD data parsing, and reproduce selected published findings. Report missing or contradictory observations rather than silently adjusting definitions or labels. Publication of a community-approved metadata catalog may still need restrictions on raw media.
