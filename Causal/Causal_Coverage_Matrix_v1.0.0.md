# Causal Atlas 1.0.0 scope and scientific readiness

**Meaning of 1.0:** versioned bounded reference content and computational teaching tools delivered against the scoped charter; not independent scientific validation, arbitrary causal inference service or external platform acceptance. Numerical tests do not grant identifiability.

| Area | Reference state | Executable support | Unfinished science / scope |
|---|---|---|---|
| Causal questions, potential outcomes, study targets | Detailed chapters, templates | Known synthetic contrasts and finite graphs | Human-reviewed real study specification; unrestricted identification |
| Confounding, d-separation, selection | Detailed diagrams/counterexamples | Finite DAG sufficient back-door checks | Actual causal structure not learned or validated |
| Baseline standardization, IPW and AIPW | Detailed derivations | Supplied probabilities/predictions; exact finite populations | Nuisance fitting, cross-fitting and defensible robust SE |
| Missing outcomes and sensitivity | Bounded methodology | Counted binary bounds, trend sensitivity | MI/censoring models and empirical mechanism checks |
| Target trial and time zero | Detailed chapter and protocol | No automatic emulation | Actual protocol with eligibility and adherence audit |
| Longitudinal treatment/confounder feedback | Detailed two-decision reference | Exact stipulated binary two-time g-formula | General long histories, observed-data fitting, MSM/g-estimation and inference |
| Multi-period/staggered DiD | Detailed group-time chapter | Supplied group means and eligible control contrasts | Covariate-adjusted estimator, interval, parallel-trend validation, clustering |
| Instrumental variables | Detailed chapters, failure cases | Supplied-mean Wald ratio, exclusion sensitivity, exact population types | Weak-IV robust intervals, real encouragement study |
| Sharp/fuzzy RD | Detailed local estimator and assumption chapters | Local line and fuzzy ratio point arithmetic | Valid bandwidth/robust inference, density tests, independent real study |
| Mediation | Interventional vs natural effects explained | Binary mediator distribution contrast | Exposure-induced confounding, fitted mediator models, longitudinal mediation |
| Interference and spillovers | Partial interference, design and exposure maps | Two-unit full potential-outcome contrasts | Network experiment, partial interference validation and clustered inference |
| External validity / transportability | Selection-target and positive-support analysis | Finite stratum reweighting with zero-support guard | Full selection diagram transport algorithms, unknown effect modifiers |
| Negative controls, bias and measurement | Design and failure guidance | Existing sensitivity experiments | Valid negative control design, bias correction, linked metrology measurements |
| Statistical uncertainty | Descriptive inference vs identification | Guarded independent-binomial normal interval | Dependence-aware, IV/RD-specific intervals, finite-sample coverage |
| Authentic historical data reproduction | Public R UCBAdmissions, 1973 | 24-count descriptive aggregation and standardization | Not a causal experiment; raw-file reuse rights and historical explanation limits |
| Source evidence | Bounded cards and exact locators | Integrity, source closure and revision preservation | Independent full-paper passage audit and expert review |
| Agent/Bitwork and desktop | Common data contracts preserved | Existing offline Forge context | Live Bitwork-to-AI/held-out evaluation, native Windows runtime checks |
