## Exact-source acquisition procedure

1. Obtain an original publisher file through an authenticated official URL in a network-enabled, lawful environment, recording redirected URLs, publisher edition, file length, retrieval date/time and transport headers.
2. Verify MIME with magic bytes, structure, number of pages, and SHA-256 against the exact captured bytes. A locally generated surrogate or webpage screenshot is not an original publisher file.
3. Record license/redistribution status for the exact original. Do not place restricted texts in the public release.
4. Link the original by content hash and precise page/equation locator to an existing Atlas source record **using a new append-only revision or a separate signed review record**, without changing prior source records.
5. Require a separate source-to-formula review: compare symbols, sign conventions, units, assumptions and differences; record discrepancies and reviewer name/signature independently of automated tests.

NIST and MIT bibliographic URLs and scientific content above inform original explanation but do not supply validated original bytes. A derived numerical oracle cannot substitute for source identity.
