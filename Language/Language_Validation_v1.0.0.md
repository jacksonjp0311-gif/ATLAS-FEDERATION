# Language Atlas v1.0.0 — executed validation and scientific boundaries

This is the **scoped content release**, not scientific peer review or an operational natural-language AI model.

- New v1 models: finite-state NFA/epsilon closure, Strong Kleene quantifier scopes, declared weighted segment alignment, staged sound-change examples, code-point n-gram overlap, byte/rights accession metadata.
- All v1 examples are original, constructed, limited and independent of real human subjects. Earlier v0.2 cases remain readable/reproducible from their unchanged archived release.
- The Unicode 18 UAX29 rev49 and UAX15 rev58 references are published standard pages, but the original normative conformance test bytes have **not** been acquired; installed Python `unicodedata` may use an older UCD version.
- All new and prior exact record/relation revisions must be checked against `evidence/previous_*_revisions_v0.2.0.json` and the complete prior release archive.
- `python -m language_atlas v1` and the v1 unit suite validate only the reference code on constructed cases. They do not validate linguistic generalization, speaker intuition, official chrF, Unicode conformance or source rights.
- External original language recordings, authentic WALS/CLDF/UD corpora, community consent attestations and independent linguist review have not been obtained.
- Full nine-node test results, the independent numerical oracle, preservation bytes, clean installed wheel and post-extraction replay are documented in the external release receipt, not presumed from this document.
