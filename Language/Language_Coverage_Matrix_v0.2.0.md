# Language Atlas v0.2.0 — Scientific coverage, methodological limits, and v1 gates

**Status: substantive development, not a finished language-science archive or independently accepted v1.0.**

| Subject | New reference and executable coverage | Scientific/archival gaps |
|---|---|---|
| Language structure and diversity | 50 source-linked chapters across speech, sign, sound, grammar, meaning, discourse and history | Primary source bytes, expert-reviewed breadth across families, native-speaker consultation |
| Unicode/orthography | NFC/NFKC profiles and UAX 29 v18 revision awareness | Full normative grapheme segmentation and official conformance vectors |
| Syntax | CYK parses and small normalized CNF PCFG inside/Viterbi | Natural-language corpora, probabilistic grammar training, genuine ambiguity judgments |
| Speech/transcription | Unit-cost token alignment and WER arithmetic | Real speech corpus, sampling/annotator disagreement, multilingual tokenization |
| Translation evaluation | Explicit unsmoothed corpus BLEU token/references | Standardized SacreBLEU/WMT configurations, independently rated semantic adequacy and cultural quality |
| Typology | Naive/observed-family balanced feature fractions, unknown counting | Authentic WALS data, phylogenetic and areal modeling, representative samples |
| Historical language research | Aligned segment-pair counts | Verified cognate sets, borrowing and chronology tests, actual reconstruction studies |
| CLDF and data portability | Original guide to source/provenance and explicit null | Full CLDF schema validator, acquired licensed dataset revisions |
| Documentation rights | Community and speaker metadata gating; no automatic publication | Real consent, restricted media storage, access correction/revocation procedures |
| Signed language modalities | Simultaneous annotation tier timing model | Original sign video and community-approved analysis; no isolated transcript can restore full sign meaning |
| Linguistic evaluation | Deterministic casebooks, regression and independent numeric checks | Real human evaluation, independent review, held-out multilingual model-quality tests |
| Primary-source survival | 33 local Language bibliography cards; rights and inspected portions recorded | 0 new authenticated original publisher bytes in this edition |
| Bitwork and deployment | Common Forge source-linked retrieval contract unchanged | All thirty domains first, then routing and integrated tests, desktop afterward |

A source reference is not an original scientific experiment; a success score on toy tokens is not a claim about cross-language intelligence. No completeness percentage is stated.
