# Language Atlas — scoped v1 content versus external validation

**What counts as done:** coherent human-reconstructible chapters, executable bounded models, exact record provenance, rights classifications, integrity manifests, prior-node preservation and independent source-tree + extracted archive software tests.

**Still open:** Unicode 18 published normative conformance data and full implementation, independently reviewed linguistic claims, community-reviewed rights/access, authentic audio/video/corpus samples, held-out model performance, culture/translation adequacy and real preservation redundancy.

A numeric score must not be described as linguistic understanding; a finite grammar must not be described as all natural language; a source URL must not be described as an archived primary document; and caller-supplied consent labels are not permission. The next domain is Energy Atlas only after this scoped v1 package passes every software and preservation gate. The Bitwork router remains last, after all 30 domains.
