# Language Atlas — v0.2 development to scoped content v1.0

**Fixed goal:** reconstruct usable knowledge of language for future human/AI readers while retaining precise rights and uncertainty, rather than merely adding volume.

**Phase A, established:** 50 theoretical chapters, 30 investigations, strict synthetic language methods, and the machine-readable common Atlas source closure. All earlier versions and the eight other nodes are preserved.

**Phase B, next substantive content:** increase coverage of actual morphology/syntax/pragmatics across language families using rights-cleared and versioned reference data, add phonological distinctive-feature systems and IPA source provenance, support multiple scripts and a conformance-tested UAX 29 segmenter, integrate stricter CLDF metadata/foreign-key checks, quantify language-sampling uncertainties under explicit family/area models, and document spoken/sign alignment methodologies with cultural rights review.

**Phase C, scoped v1 gate:** publish a complete bilingual and cross-language scientific reference with original worked derivations, independent offline oracles, exact source/version qualifications, realistic counterexamples, and honest named limitations. This content readiness is separate from human speaker/community review, authenticated corpus acquisition, model-quality gains, or native Windows deployment.

**Global milestone:** complete all thirty scientific domain libraries before building the Bitwork router. Do not implement a domain-specific retriever or desktop transfer now.
